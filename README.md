# 🚀 SaaS Portfolio Dashboard

A modern portfolio platform designed as a **Personal Operating System**, combining professional branding, interactive analytics, achievements, social presence, and digital assets within a unified SaaS-inspired experience.

Unlike traditional portfolio websites, this project transforms a personal brand into a fully interactive dashboard where visitors can explore projects, achievements, career milestones, and real-time activity through an immersive user experience.

---

# ✨ Overview

The SaaS Portfolio Dashboard serves as a centralized digital headquarters for showcasing:

* Professional experience
* Technical projects
* Career achievements
* Social platforms
* Digital assets
* Personal mission and vision
* Interactive analytics

Built with modern frontend technologies and designed using SaaS UI principles, the platform delivers a premium and engaging experience across desktop and mobile devices.

# ⚙ Development

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

Run linting:

```bash
npm run lint
```
